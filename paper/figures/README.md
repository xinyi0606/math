## 使用边界

- Q1 仅对应附件 1 的确定性典型日；当前费用和敏感性数字仍按项目状态标为未最终冻结。
- Q2 评价期为 2025-02-01 至 2025-12-31，共 334 天，不写成 365 天。
- Q2 直接预测净负荷，不写成分别训练负荷和光伏两个模型。
- Q2 的每日 LP 优化日前计划购电费用；5 倍紧急购电费用在事后回放结算，不写成已进入日前风险目标。
- 泰勒图只反映中心化误差，必须与 RMSE/MAE 指标表共同解释。
- 典型日由事后诊断选取，不用于训练、选参或证明普遍最优。

原始证据表保存在 `Q1/figure_evidence.csv` 与 `Q2/figure_evidence_full.csv`；验证记录保存在相邻 JSON 文件中。
