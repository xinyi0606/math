# Q1/Q2/Q3/Q4 论文图表清单

本目录保存已审查的 Q1、Q2、Q3、Q4 中文论文图。Q1、Q2和Q4保留原图包的多格式文件，Q3正文采用7张600 dpi PNG。

- `PNG_600dpi/`：600 dpi 高清位图，适合直接插入 Word；
- `PDF_vector/`：矢量 PDF，适合 LaTeX 或排版软件；
- `SVG_editable/`：可编辑矢量图；
- `grayscale/`：灰度可读性检查版。

统一使用用户提供的黑体文件 `paper/fonts/黑体.ttf`。本次没有重新安装系统字体。

## 采用结论

参考图包经证据核对后可作为论文图源，无须重新生成：

- Q1 图的数值来自当前 `q1_schedule.csv`、`q1_dp_grid_convergence.csv` 和 `metrics.json`；原包视觉审查记录无问题。
- Q2 图包登记的附件、预测缓存、逐日指标和全量调度文件 SHA-256 与当前仓库完全一致；原包验证报告为 PASS。
- Q4 图包与复现证据共同说明了源码真实目标、价格信息边界及有限情景局限；正文采用其中7张，且已据此纠正“紧急费用进入鲁棒目标”和“价格oracle是严格下界”两项错误口径。
- Q3图包基于第二轮$\alpha=0.99$结果和334天逐日回放生成；正文选用7张，覆盖滚动机制、费用—风险前沿、尾部正反证据、配对日差异、安全裕度更新、全年购电调整和典型日联动。图内方法名称已展开，不再使用M1、M2、M3缩写。
- 本机再次检查了正文采用的25张彩色 PNG，未见中文缺字、裁切、图例遮挡或色标缺失；其中7张Q3图及本次改名重导出的图均为600 dpi。
- Q2 独立复核脚本本机未完整重跑，因为当前环境缺少可选依赖 `pypdf`。因此 PDF 字体嵌入状态沿用原包报告，不表述为本机复验通过；论文优先使用 600 dpi PNG，SVG 用于后续编辑。

## 使用边界

- Q1 仅对应附件 1 的确定性典型日；当前费用和敏感性数字仍按项目状态标为未最终冻结。
- Q2 评价期为 2025-02-01 至 2025-12-31，共 334 天，不写成 365 天。
- Q2 直接预测净负荷，不写成分别训练负荷和光伏两个模型。
- Q2 的每日 LP 优化日前计划购电费用；5 倍紧急购电费用在事后回放结算，不写成已进入日前风险目标。
- Q3安全裕度使用“预测光伏减实际光伏”的高估误差，且只读取目标日前历史；$\alpha=0.99$不等于实际覆盖概率保证。
- 泰勒图只反映中心化误差，必须与 RMSE/MAE 指标表共同解释。
- 典型日由事后诊断选取，不用于训练、选参或证明普遍最优。
- Q4鲁棒LP优化所选历史价格情景中的最坏合同费用；5倍紧急费用在真实轨迹回放中结算。
- Q4价格oracle只预知价格、仍使用预测净负荷，不是实际综合费用的严格下界。
- Q4有限七情景最坏值不构成真实未来费用保证；Q4-2中有101天的实际计划费用超过对应有限情景最坏计划费用。
