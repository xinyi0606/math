# Q4正文配图筛选说明

本目录从用户提供的34张Q4中文高清候选图中筛选7张正文图。选择目标是一图一论点，并覆盖信息边界、价格时空结构、情景覆盖、费用—风险比较、oracle边界、储能状态和有限情景失效诊断，避免堆叠简单统计柱状图。

| 图号 | 正文角色 | 关键边界 |
|---|---|---|
| Q4-02 | 解释价格前缀条件化与非前视情景选择 | 真实未来价格不参与选择 |
| Q4-05 | 描述334天价格的日期—时段结构 | 仅作事后EDA |
| Q4-11 | 展示最高费用日的七情景与真实后缀 | 包络不是置信区间 |
| Q4-13 | 比较两分支三策略的累计费用—紧急量 | 三点不构成连续Pareto前沿 |
| Q4-18 | 证明价格oracle并非逐日严格费用下界 | 仍使用预测净负荷 |
| Q4-28 | 审计跨日SOC连续性和两分支轨迹 | 颜色统一为1.2—10.8 MWh |
| Q4-34 | 诊断有限情景最坏计划费用的越界 | 不构成真实未来费用保证 |

每张图保留600 dpi PNG、PDF、SVG与灰度版本。正文优先引用PNG；PDF存在中文字体嵌入警示时优先使用SVG。完整34图证据索引与验证报告分别保存在`figure_evidence_full.csv`和`verification_report.json`。
