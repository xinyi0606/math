# Q4 候选方法池

> 状态：3个候选均完成真实数据 PoC；价格信息边界已确认为滚动获知，建模者已选择Q4-M3进入全年实验
> 统一符号见 `planning/symbol_table.md`

## 1. 小问摘要

- **目标**：仅将外网价格替换为附件4的日内/日间波动轨迹，保持Q2/Q3物理约束、信息集和结算机制，分别重算 `result4-2.xlsx` 与 `result4-3.xlsx`。
- **类型**：情景分析—优化混合问题。
- **输入**：附件2实际负荷/光伏、附件3预测、附件4价格。
- **输出**：Q4-2和Q4-3完整策略、成本、紧急购电及相对固定电价的变化。
- **依赖**：正式实现必须继承建模者最终选定的Q2/Q3方法；PoC先验证价格响应核心。

## 2. 候选方法

### M1：波动价格下无储能动作基线 `[BASELINE — PoC PASS]`

- **数学思想**：以首个真实日为小样本，令储能不动作，按 $g_t=[l_t-v_t]_+$ 在附件4价格下结算。
- **适配理由**：隔离负荷/光伏本身的购电成本，为价格感知储能优化提供下界之外的可行参照。
- **优势**：完全透明；不受SOC调度影响；便于计算储能价值。
- **弱点**：不响应价格波动，不能作为最终竞争策略。
- **程序员预期输出**：Q4-2/Q4-3无储能基线费用、按日价格与净负荷贡献。
- **评价指标**：成本、可行性、其他候选相对节省率。
- **实现难度**：easy；**估计正式实现时间**：0.5 h。
- **数据需求**：附件2净负荷、附件4价格。
- **文献支持**：P1价格套利模型的无储能参照。
- **首轮优先级**：基线必须保留；方法选择由建模者决定。
- **PoC**：`methods/Q4/poc/q4_m1_no_storage_poc.py`（14行）。
- **可行性数值**：2025-01-01费用 **86577.76元**；终端误差及平衡违例均为0；运行约0.011 s。
- **PoC结论**：PASS。

### M2：确定性波动电价重优化 `[ORACLE COMPARATOR — PoC PASS]`

- **数学思想**：保持Q2/Q3候选的预测与执行机制，只把目标函数中的固定日型电价替换为 $p_{d,t}$，逐日/滚动求解线性储能调度。
- **适配理由**：严格满足Q4“在波动电价下重新计算”的最小变更原则，能将差异归因于价格输入。
- **优势**：复用性强；计算快；策略与固定电价结果可直接对照。
- **弱点**：建模者已确认价格滚动获知，因此使用全天真实价格的当前PoC具有前视，只能作为oracle对照；若改为可实施滚动策略，必须为未来时段另设非前视价格场景。
- **程序员预期输出**：Q4-2/Q4-3模板、固定/波动价成本差、SOC和购电时段迁移、约束审计。
- **评价指标**：总费用、节省率、$R_E$、峰谷购电迁移量、运行时间。
- **实现难度**：medium；**估计正式实现时间**：Q2/Q3完成后3 h。
- **数据需求**：附件2-4和已选Q2/Q3方法工件。
- **文献支持**：P1分时价格响应与不同价格轨迹重算。
- **首轮优先级**：AI建议在learning模式下暂不公开。
- **PoC**：`methods/Q4/poc/q4_m2_price_aware_lp_poc.py`（19行）。
- **可行性数值**：2025-01-01费用 **74061.30元**，较M1低 **14.46%**；终端误差0；运行约0.034 s。
- **PoC结论**：PASS；证明完全信息下的价格响应LP可解，但在已确认的滚动信息边界下仅作oracle。

### M3：历史价格情景最坏费用鲁棒LP `[CHOSEN — PoC PASS]`

- **数学思想**：以多个真实日的价格/净负荷轨迹构成情景集，最小化共同储能动作下的最坏情景费用 $C^{worst}$；正式版本可在Q2/Q3信息结构中滚动更新情景集。
- **适配理由**：检验价格轨迹不可完全确定时，牺牲平均成本换取最坏费用控制的可行性。
- **优势**：不生成虚构价格；风险目标清楚；可与确定性解比较保守性。
- **弱点**：PoC共同动作是假设性压力测试；情景覆盖有限，且正式Q4是否需要鲁棒扩展仍由建模者判断。
- **程序员预期输出**：情景费用分布、最坏/平均成本、相对M2保守性、情景留出验证。
- **评价指标**：$C^{worst}$、平均费用、尾部费用、约束违例和运行时间。
- **实现难度**：hard；**估计正式实现时间**：6 h。
- **数据需求**：仅使用各决策时刻之前的附件4历史真实价格轨迹，以及匹配的附件2净负荷与Q2/Q3预测输入。
- **文献支持**：P2/P3鲁棒调度思想；此处仅作轻量价格情景扩展。
- **首轮优先级**：AI建议在learning模式下暂不公开。
- **PoC**：`methods/Q4/poc/q4_m3_scenario_robust_poc.py`（22行）。
- **可行性数值**：前三个真实日情景最坏费用 **74373.25元**、平均费用 **61421.65元**；终端误差 $3.64\times10^{-12}$ kWh；运行约0.049 s。
- **PoC结论**：PASS；数值只说明小型min-max模型可解，不与M2单日费用直接作优劣判断。

## 3. 分析性拒绝方法

| 方法 | 拒绝原因 |
|---|---|
| 直接按电价比例缩放Q2/Q3购电量 | 最优充放电时段会改变，比例缩放不能保证可行或最优。 |
| 另建复杂电价预测模型作为主线 | 题面给出附件4价格且未要求预测；会扩张任务并混淆Q4归因。 |
| 元启发式多目标调度 | 当前主要目标和约束可线性化，额外随机算法不利于复核。 |

## 4. 基线指定

- **基线**：M1波动价格下无储能动作。
- **理由**：在同一真实价格和净负荷下量化储能/调度的直接价值。

## 5. 已确认信息边界与待定方法

- **已确认边界**：附件4价格滚动获知，同日未来真实价格不得前视。
- **方法影响**：M1继续作为无储能基线；使用全天真实价格的M2降级为oracle比较；M3可在严格使用历史价格情景时形成可实施主候选。
- **建模者选择**：Q4-M3进入全年实验；M1保留为无储能基线，M2保留为完全信息oracle。
- **选择边界**：M3的PoC只证明情景鲁棒结构可解且满足物理约束；不同样本窗口下的M1/M2/M3费用不得直接排序。
- **正式验证**：逐日仅用历史价格更新情景，比较全年总费用、最坏日费用、紧急购电、SOC可行性、相对oracle机会损失及情景敏感性。
