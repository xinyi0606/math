# Q2 候选方法池

> 状态：3个候选均完成真实数据 PoC；建模者已选择M3进入全年预测—优化实验，M1保留为基线，M2保留为对照
> 公平比较窗口：2025-01-22至2025-01-28；统一符号见 `planning/symbol_table.md`

## 1. 小问摘要

- **目标**：每日00:00仅用当时可知信息预测当天负荷/光伏或净负荷，并与储能优化耦合；实际缺口按5倍电价紧急购电。
- **类型**：预测—优化混合问题。
- **输入**：附件1固定电价、附件2截至决策时刻的历史负荷和光伏。
- **输出**：2025-02-01至12-31的 `result2.xlsx` 与四个指定日明细。
- **依赖**：复用Q1物理模型；1月数据仅用于训练、初始化和预热。

## 2. 候选方法

### M1：前一日同槽持久性预测 + 确定性LP `[BASELINE — PoC PASS]`

- **数学思想**：以昨日同一10分钟时段的净负荷作为今日预测，再将 $\widehat n_{d,t}$ 输入Q1线性调度模型；执行时按实际缺口计算 $g^E_{d,t}$。
- **适配理由**：严格非前视，构成时序预测最简单且可复现的基线。
- **优势**：无需训练；计算极快；错误来源清晰。
- **弱点**：对天气、工作日和季节变化敏感；单日突变会直接传递。
- **程序员预期输出**：预测序列、计划/SOC、紧急购电、按日成本和误差表。
- **评价指标**：RMSE、MAE、全年费用、$R_E$、极端日费用和可行性。
- **实现难度**：easy；**估计正式实现时间**：1.5 h。
- **数据需求**：前一日及更早的附件2数据、附件1电价。
- **文献支持**：P2/P3要求与复杂模型比较的简单日前基线。
- **首轮优先级**：基线必须保留；候选选择由建模者决定。
- **PoC**：`methods/Q2/poc/q2_m1_persistence_poc.py`（12行）。
- **可行性数值**：RMSE **1270.33 kW**，MAE **751.36 kW**；欠预测电量 **64866.84 kWh**，5倍紧急购电成本代理 **261011.20元**；运行约0.285 s。
- **PoC结论**：PASS。

### M2：近7日同槽均值 + 确定性LP `[COMPARATOR — PoC PASS]`

- **数学思想**：对每个10分钟槽取过去7日净负荷均值作为预测，以平滑单日噪声；随后使用与M1相同的储能LP和执行结算。
- **适配理由**：仍严格非前视，但比单日持久性更稳健，能表达周内短期水平。
- **优势**：易解释、无高容量模型；对偶发异常日较稳。
- **弱点**：滞后于快速季节变化；均值可能压平峰值并增加紧急购电。
- **程序员预期输出**：3/7/14日窗口对比、预测与调度结果、紧急购电明细。
- **评价指标**：与M1相同，另检查窗口敏感性和峰值低估率。
- **实现难度**：easy；**估计正式实现时间**：2 h。
- **数据需求**：至少过去7日附件2数据。
- **文献支持**：作为P2/P3不确定性方法之前的平滑统计基线。
- **首轮优先级**：AI建议在learning模式下暂不公开。
- **PoC**：`methods/Q2/poc/q2_m2_rolling_mean_poc.py`（14行）。
- **可行性数值**：RMSE **1044.67 kW**，MAE **823.39 kW**；欠预测电量 **66907.21 kWh**，5倍紧急购电成本代理 **273087.94元**；运行约0.278 s。
- **PoC结论**：PASS；相较M1降低RMSE但提高MAE，不能只凭单指标判断。

### M3：滞后/日历特征梯度提升 + 确定性LP `[CHOSEN — PoC PASS]`

- **数学思想**：用昨日同槽、近7日均值、日内正余弦和星期特征拟合非线性梯度提升回归，输出净负荷预测；优化和结算层与M1/M2保持一致。
- **适配理由**：附件2有全年高频样本，树模型可捕捉负荷与光伏合成后的非线性日型。
- **优势**：PoC误差明显更低；能处理特征交互；训练仍较快。
- **弱点**：解释性低于统计基线；需要严格时间切分和防泄漏审计；分布外推风险较高。
- **程序员预期输出**：时间滚动验证、特征贡献、预测/计划/紧急购电、成本分解。
- **评价指标**：RMSE、MAE、分月误差、全年总费用、$R_E$、训练/推理时间。
- **实现难度**：medium；**估计正式实现时间**：4 h。
- **数据需求**：至少7日历史；正式训练使用截至每日00:00的数据与日历特征。
- **文献支持**：P2/P3的预测误差—调度成本链条；算法本身无直接指定。
- **首轮优先级**：AI建议在learning模式下暂不公开。
- **PoC**：`methods/Q2/poc/q2_m3_gradient_boosting_poc.py`（19行）。
- **可行性数值**：RMSE **301.91 kW**，MAE **196.96 kW**；欠预测电量 **15258.78 kWh**，5倍紧急购电成本代理 **54992.61元**；运行约0.46 s。
- **PoC结论**：PASS；优势需在滚动时间验证和下游成本中复核。

## 3. 分析性拒绝方法

| 方法 | 拒绝原因 |
|---|---|
| 使用当天未来实测值的oracle | 违反00:00信息边界，只能作为不可实现的下界。 |
| LSTM/Transformer | 虽有高频样本，但仅一年、天气外生变量缺失；实现和过拟合风险高于当前必要程度。 |
| Wasserstein分布鲁棒优化直接作主模型 | 可作为后续扩展，但候选阶段尚未证明样本量和计算收益足以支撑其复杂度。 |

## 4. 基线指定

- **基线**：M1前一日同槽持久性 + 确定性LP。
- **理由**：严格非前视、无训练假设，是预测改进必须超越的最低参照。

- **主候选**：M3梯度提升；统一窗口RMSE为301.91 kW，进入全年预测—优化联动实验。
- **基线与对照**：M1保留为透明基线；M2保留为简单平滑对照，二者均不作主模型。
