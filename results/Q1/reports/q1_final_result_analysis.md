# Q1 最终结果分析

> 状态：未冻结写作材料；采用方法由 `Q1-D01` 选择。

## 1. 结果

Q1-M2 的全天购电费用为 **35,126.95 元**，M1 为 **48,052.05 元**，节省 **12,925.10 元（26.90%）**。全天购电量、充电量和放电量分别为 59,482.70、20,740.67 和 16,799.94 kWh。

可行性审计显示最大平衡残差为 $1.14\times10^{-13}$ kWh，终端 SOC 误差为 $6.37\times10^{-12}$ kWh，SOC 位于 1200—10800 kWh，且无同时充放电。

## 2. 数值核验与图表

- `results/Q1/experiments/round1/figures/q1_dispatch.png`：展示负荷、光伏、购电和 SOC 轨迹，用于说明高低价时段的储能调度。
- `results/Q1/experiments/round1/tables/q1_dp_grid_convergence.csv`：DP 网格由 400 kWh 加密至 50 kWh 时，相对 LP 差距由 6.40% 缩至 0.79%，支持连续解的数值一致性。

## 3. 可写结论与限制

可写“在给定单日预测和题设约束下，储能调度降低购电费用 26.90%”。不可写“长期运行必然节省 26.90%”；时间标签、效率和电池退化敏感性尚未覆盖。
