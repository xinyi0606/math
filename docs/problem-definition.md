# C 题：微网与外部电网电力调控策略

## 1. 项目目标

利用小区负荷、光伏发电、储能状态和外网电价，在满足负荷需求及储能约束的前提下，优化微网日前购电与日内调整策略，使总购电费用尽可能低。

原始题面保存在同目录的 `C题.pdf`。本文件是便于建模和协作的结构化梳理；若表述存在差异，以原始题面和官方补充说明为准。

## 2. 已知储能参数

| 参数 | 数值 |
|---|---:|
| 最大容量 | 12000 kWh |
| 最大充放电功率 | 5000 kW |
| 2025-01-01 00:00 初始储能量 | 6000 kWh |
| 运行储能量下限 | 1200 kWh |
| 运行储能量上限 | 10800 kWh |

“充放电效率为 90%”在实现前需明确是充、放电各取 90%，还是往返效率为 90%；未得到官方说明时，应在论文中声明采用的解释并做敏感性分析。

## 3. 四个问题

### 问题 1：单日确定性计划

- 每天的电价和小区负荷相同，给出光伏发电功率的一天预测。
- 微网提供的电能不得低于小区负荷。
- 储能设备 00:00 与 24:00 的储能量相同。
- 每天 00:00 制定当天计划购电策略。
- 根据附件 1 和附录 1 求解，填写 `result1.xlsx`。

论文需给出 10:00-10:10、12:00-12:10、14:00-14:10、16:00-16:10、18:00-18:10、20:00-20:10 的购电量，以及全天购电量和购电费；还需给出每 4 小时区间的充、放电量及 00:00、24:00 储能量。

### 问题 2：全年日前计划与紧急购电

- 每天采用相同的分时电价，小区负荷和光伏实际功率随时间变化。
- 若计划供电不足以满足负荷，缺口由外网紧急购电补足。
- 紧急购电单价为交易时刻正常电价的 5 倍。
- 非紧急部分按计划购电量计费。
- 每天 00:00 制定当天策略。
- 使用附件 1、附件 2，填写 `result2.xlsx`，覆盖 2025-02-01 至 2025-12-31。

论文需对 2025-03-20、2025-06-21、2025-09-23、2025-12-21 按表 1、表 2、表 3 的格式分别给出计划购电、储能充放电与日首日末储能量、紧急购电时段和购电量。

### 问题 3：滚动光伏预测与购电调整

- 每天 00:00、06:00、12:00、18:00 可获得未来 24 小时整点光伏功率预测。
- 00:00 预测用于制定计划购电；其他时刻的预测可用于调整策略。
- 计划购电量高于调整购电量的部分，违约电价为交易时刻电价的 50%。
- 调整购电量高于计划购电量的部分，超出部分单价为交易时刻电价的 1.5 倍。
- 总购电费用包含计划购电费、紧急购电费和购电调整相关费用。
- 使用附件 1-3，填写 `result3.xlsx`，并分析是否需要采用日内新预测调整购电策略。

结果覆盖 2025-02-01 至 2025-12-31，并按题面要求保存计划购电量、调整购电量、最终充放电量和最终紧急购电量。

论文同样需对上述四个指定日期按表 1、表 2、表 3 的格式给出相应结果。

### 问题 4：波动电价

- 外网电价改为随日期和时刻实时变化。
- 使用附件 2 的负荷及光伏实际数据、附件 3 的光伏预测和附件 4 的电价。
- 在波动电价下重新求解问题 2 和问题 3。
- 分别填写 `result4-2.xlsx` 和 `result4-3.xlsx`。

## 5. 建模时必须统一的约定

- 时间步长：题目输出以 10 分钟为主，即每步为 1/6 小时；附件实际粒度到手后再核对。
- 功率转能量：每步能量等于功率乘以时间步长，不能直接把 kW 当作 kWh。
- 功率平衡：外网购电、光伏利用和储能放电共同满足负荷及储能充电需求。
- 储能状态：限制每步充放电功率与储能量上下界，并避免无意义的同时充放电。
- 跨日状态：问题 2-4 应让前一天 24:00 的储能量衔接下一天 00:00；问题 1 另有日首尾相同约束。
- 数据边界：附件中 `0:00+1` 表示次日 00:00，即当日 24:00。
- 结果验证：逐时检查能量平衡、约束违例、费用分项及 Excel 模板完整性。
