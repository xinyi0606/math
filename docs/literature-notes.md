# 主要参考文献与使用边界

本项目的题面为“微网与外部电网电力调控策略”。以下三篇学位论文是主要参考文献，用于理解微网调度、储能约束、分时电价及预测不确定性；不替代题目附件、结果模板或题面中明确的费用规则。

原始PDF已于2026-09-12从用户此前提供的本机路径归档到 `workspace/papers/`，供项目内可追溯分析。三份原文合计约25 MB；推送前仍需按仓库容量与版权要求确认是否纳入远程仓库。正式原文分析见 `workspace/papers/related_paper_analysis.md`。

## 1. 分时电价下光储微电网多时间尺度协调运行策略研究

李德兴. *分时电价下光储微电网多时间尺度协调运行策略研究*[D]. 南昌大学, 2025.

### 与本题的对应关系

- 直接对应“分时电价 + 光伏 + 储能 + 并网微电网”的基本场景。
- 将运行划分为日前优化与日内实时控制，能支撑问题 1/2 的日前计划、问题 3 的日内调整这一主线。
- 讨论电池状态、充放电功率、峰谷套利与运行成本，适合参考统一的储能状态转移和约束表达。

### 本项目的采用方式

- 用作问题 1/2 的线性成本目标、功率平衡和储能约束的写作依据。
- 用作问题 3“日前-日内”双时间尺度框架的背景依据。

### 不直接照搬的内容

- 文中包含电动汽车负荷与改进灰狼优化算法；本题未给出电动汽车数据，且本题的线性费用规则优先采用可验证的线性/混合整数优化。
- 算法优劣不应只依据单个算例，应以本题的可行性、费用和模板输出为准。

## 2. 计及预测不确定性的智能微电网协调控制与优化运行研究

袁志鹏. *计及预测不确定性的智能微电网协调控制与优化运行研究*[D]. 北京交通大学, 2024.

### 与本题的对应关系

- 将预测误差纳入微电网优化运行，和问题 3 提供 00:00、06:00、12:00、18:00 多次光伏预测高度相关。
- 讨论日前-日内两时间尺度协调、滚动优化和模型预测控制，可为日内调整决策提供方法论。
- 提供以分布鲁棒、机会约束等方法描述预测不确定性的扩展方向。

### 本项目的采用方式

- 将问题 3建模为“00:00 日前计划 + 新预测到达时的滚动再优化”。
- 在论文讨论中用预测误差与调整费用之间的权衡解释为何要比较“是否采用新预测”。
- 数据到齐后，可额外做预测误差分布或情景敏感性分析，作为稳健性验证。

### 不直接照搬的内容

- 分布鲁棒机会约束、Wasserstein 模糊集和多微网协同属于可选扩展；若题面数据不足，不应替代题目明确的 50%、1.5 倍和 5 倍电价规则。
- 文中通信安全、分布式控制等内容不属于本题的交付范围。

## 3. 考虑源荷不确定性的楼宇微电网多时间尺度供需侧管理研究

张宇航. *考虑源荷不确定性的楼宇微电网多时间尺度供需侧管理研究*[D]. 山东大学, 2024.

### 与本题的对应关系

- 同时关注光伏侧与负荷侧不确定性，与问题 2/3 的实际负荷、实际光伏和预测光伏偏差相呼应。
- 给出日前、日内、实时的多阶段调度思路，可帮助说明“预报更新后才调整”的决策时点。
- 对不确定性集合、随机鲁棒优化和结果可靠性检验有参考价值。

### 本项目的采用方式

- 用于论文中“源荷不确定性导致日前计划偏差”的分析框架。
- 用于设计敏感性分析：比较不调整、固定时点调整和多时点调整的费用与紧急购电量。

### 不直接照搬的内容

- 该文面向楼宇，包含温控负荷与需求响应；本题未提供可调负荷或建筑热模型，不能自行假设。
- 三阶段随机鲁棒模型应作为论文的延伸讨论，不能掩盖题面要求的基础结果。

## 统一的论文叙事

建议采用以下主线：

```text
分时电价驱动的储能套利
        +
负荷与光伏偏差带来的供需风险
        +
预测更新带来的日内再优化机会
        ↓
日前计划 - 日内滚动调整 - 实时紧急补电
```

基础模型严格按题面求解；多时间尺度、预测不确定性与鲁棒性方法用于解释模型设计、开展对比试验和讨论局限性。
