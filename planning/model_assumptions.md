## 1. 假设与题面规则的边界

下列内容已经由题面或冻结口径直接规定，是模型边界/约束，不再伪装成可自由选择的假设：

| 类别 | 已冻结内容 |
|---|---|
| 时间与单位 | 10分钟为主时间步，功率乘 `1/6 h` 转为时段电量；主模型按模板列序解释时间标签 |
| 储能机制 | `1200\le E_{n,t}\le10800 kWh`，最大充放电功率5000 kW，主模型 `\eta_c=\eta_d=0.9`，同一时段不得同时充放电 |
| 能量机制 | 负荷必须满足；允许弃光；不允许用负购电表示向外网售电 |
| 信息边界 | Q2日前计划严格非前视；当天未来实际负荷与光伏只用于执行核算和后续更新 |
| 预测映射 | 附件3整点预测按冻结规则线性插值至10分钟，首节点不得使用未来信息 |
| 调整结算 | `q^A` 是最终调整后的总量；取消量退款50%，上调量按1.5倍，紧急购电按5倍；只与原计划比较一次 |
| 状态边界 | Q1日首日末相同；Q2-Q4跨日连续，主模型全年末储能量为6000 kWh |

本文件只记录为使上述边界可被数学模型执行而额外采用的真实性、可观测性、稳定性和简化条件。

| Q1日首尾相等 vs Q2-Q4跨日连续 | 不冲突；终端条件按题号不同 | Q1用 `E_0=E_{144}`；Q2-Q4只在全年末固定6000 kWh |
| Q2实际值仅用于核算 vs Q3日内预测更新 | 不冲突 | Q3仍只用发布时刻可得预测，未来实测值继续禁止前视 |
| Q3多次调整 vs 单次结算 | 已由冻结口径化解 | 只保存最后有效总量并与原计划比较一次 |
| Q4“实时变化电价” vs 日前/滚动决策 | **潜在冲突，未关闭** | 由D-A02确认价格信息时点；不得默认全日实价可提前获知 |
| 日前储能计划 vs 实际执行recourse | **潜在冲突，未关闭** | 由D-A01、D-A03确定决策层次后再形成候选方法 |

## 10. 方法选择后强制回填项

`method-selector` 产生候选方法池后，本文件必须新增或修订以下内容：

1. 各负荷/光伏预测候选的平稳性、季节性、样本独立性、特征可得性和误差分布假设；
2. 确定性、情景随机、鲁棒或分布鲁棒优化各自的不确定性集合及风险偏好假设；
3. 若采用CVaR，补充尾部风险概率与损失分布假设；若采用MPC，补充滚动窗口、终端价值和执行延迟假设；
4. 充放电互斥使用互补约束、二进制变量或价格机制保证时，各自的适用条件；
5. D-A01至D-A03的建模者决定，以及这些决定对Q1-Q4候选方法的排除或保留结果；
6. 每个新增假设的类型和违反影响重新使用 `[AI-DRAFT — modeler must confirm: ...]` 标记，直至建模者明确确认。
